# Davide Gena | Portfolio

This [portfolio](https://davidegena.github.io/) is my crazy little lab where you can find the completed projects and crazy drafts of what I would like to accomplish. Have fun ;)

## How to run in local:

1. Download and install [Node.js v16.20.2](https://nodejs.org/en/download);
2. Run `npm install --legacy-peer-deps`;
3. `npm start` to start a local server;
4. And `npm run build -- --configuration production` to build the final project.
